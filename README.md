## مهم جدًا قبل الاستخدام الحقيقي
هذه نسخة Static مناسبة للتجربة وGitHub Pages. لا تستخدمها لتخزين كلمات مرور حقيقية أو بيانات عملاء حقيقية، لأن localStorage وJavaScript في المتصفح غير مناسبين كقاعدة بيانات آمنة.

لتحويلها إلى منصة حقيقية:
1. استخدم Firebase/Supabase أو Backend خاص للمصادقة وقاعدة البيانات.
2. اجعل Admin Authorization على الخادم.
3. خزّن كلمات المرور باستخدام نظام Auth موثوق، وليس localStorage.
4. اربط Fawry من Backend فقط، وضع Secure Key كـ environment secret.
5. استخدم HTTPS وسياسات صلاحيات للمنتجات والطلبات والمستخدمين.

## النشر على GitHub Pages
ارفع `index.html`, `admin.html`, `app.js`, `admin.js`, `style.css`, `README.md` إلى repository، ثم:
Settings → Pages → Deploy from branch → main → /(root).
